# 🚗 Détection de Plaques d'Immatriculation

Application web permettant de détecter et lire automatiquement les plaques d'immatriculation à partir d'images.

## 🛠️ Technologies utilisées
* **Backend :** Python / Flask (`app.py`)
* **Frontend :** HTML / CSS (`templates/index.html`)
* **Traitement d'image / OCR :** OpenCV / EasyOCR *(à adapter selon vos bibliothèques)*
